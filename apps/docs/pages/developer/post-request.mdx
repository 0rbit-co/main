# POST Request

__0rbit__ enables an `ao` process to __FETCH ANY DATA__ using the data body to make a POST request on the Internet.

This is done by sending the `data body` and the URL to the `0rbit` process, which will make the POST request to the `URL` with the `data body` and send the response back to the `ao` process.

> `0rbit` process returns the data in the format the provided URL returns.

## Post Request Handler

This method accepts the following tags:
| __Tag__ | __Description__ ||
| --- | ----------- | ------- |
| `["X-Action"]` | The type of request. | Required |
| `["X-Url"]` | The URL from which you want to fetch the data. | Required |
| `["X-Body"]` | The data body in the `json` encoded string to be sent in the POST request. | Optional |
| `["X-Headers"]` | The headers in the `json` encoded string to be sent in the POST request. | Optional |
| `["X-Min-Fee"]` | The minimum fee you will pay for the request. | Optional |
| `["X-Max-Fee"]` | The maximum fee you will pay for the request. | Optional |
| `["X-Valid-For"]` | The time for which the request is valid. | Optional |

## Fee

Each request on 0rbit cost some fee in the form of $0RBT Points. Currently, the fee is set to constant at 1 $0RBT Point per request. 

The process which will be sending the GET request to 0rbit needs to have $0RBT Points, which will be transferred per request. 

> To get $0RBT Points, DM [@megabyte](x.com/megabyte).
